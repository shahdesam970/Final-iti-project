# Online Store

A React shopping app with a product catalog, cart and checkout.

## Features
- Product listing, category list and product details pages
- Product data from the public DummyJSON API
- Shopping cart with a quantity selector
- Checkout page
- Redux Toolkit state for the cart and theme
- Loader and not-found pages

## Built with
React, Redux Toolkit, React Router, Axios, DummyJSON API

## Run locally
1. `npm install`
2. `npm start`
